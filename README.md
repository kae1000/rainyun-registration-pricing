## 首月 5 折、年付 7 折、积分商城：三条路各自的限制

**首月 5 折券**基本全品类通用，但有几个明确的例外。湖北区域的机器受当地限价政策影响，本身就是底价出售，不能用券；单张券只能用一次，券面额大于订单金额时不找零、不退差价；带“推广”标识的特殊券官方可能随时收回。券从发放那天起算 30 天，攒着不用就作废了。

**年付 7 折**是给确定长期用的人准备的，全年按七折计价，一次付清。年付折扣和首月 5 折券属于两套机制，可以同时享受。只是想试水的，先买一个月，别一上来付一年。

**积分商城**走的是另一条线。签到、做任务、消费都返积分，积分能兑优惠券和商城商品。节假日前后（五一、春节、双十一）会放限时券，力度比平时大，这些券每晚 20:00 补库存。
